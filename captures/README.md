# Captures d'écran des projets

Dépose ici une image par projet, nommée comme le repo GitHub :

- `AgroFly.png` pour le repo `AgroFly`
- `otakuverse_V2.jpg` pour le repo `otakuverse_V2`

Formats acceptés : png, jpg, jpeg, webp, gif. Format conseillé : 16:9 (par exemple 1600×900), moins de 500 Ko.

Une image déposée ici est prioritaire sur celle trouvée automatiquement dans le README du repo.
Pour un projet sans repo (comme Blue), ajoute `"image": "captures/blue.png"` à son entrée dans `data/featured.json`.
